# Life in the UK – Keywords Cards

Interactive flip cards for revising the Life in the UK test.

## Features
- Organised by official handbook chapters (2–5)
- Click / tap any card to flip and see the association
- Search across all keywords, people and facts
- Filter by chapter
- Mobile-friendly
- Pure static HTML – no build step required

## Deploy to Vercel (easiest)

1. Create a new repo or folder
2. Put `index.html` inside it
3. Run:
   ```bash
   npx vercel
   ```
   or drag-and-drop the folder onto [vercel.com/new](https://vercel.com/new)

That’s it. You get a live URL immediately.

## Local preview
Just open `index.html` in any browser, or:
```bash
npx serve .
```

## Content coverage
- **Ch.2** Nations, capitals, patron saints, geography
- **Ch.3** Key dates, monarchs, major events, Pankhurst, Churchill, Thatcher…
- **Ch.4** Scientists & inventors, sports & athletes, writers & culture
- **Ch.5** Parliament, devolution, voting, fundamental principles

Based on the official *Life in the United Kingdom: A Guide for New Residents* (3rd edition).
